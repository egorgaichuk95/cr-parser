# 📊 Crypto Parser Bot

Telegram-бот для парсинга данных из `.json` файлов и генерации аналитических отчетов в формате Excel (`.xlsx`). Оптимизирован для работы на мобильных устройствах (в частности, iPhone 12).

---

## 🚀 Быстрый запуск через Docker Compose

Это рекомендуемый способ запуска. Все зависимости уже настроены внутри контейнера.

### 1. Подготовка
Убедитесь, что у вас установлены **Docker** и **Docker Compose**. Получите токен бота у [@BotFather](https://t.me/BotFather).

### 2. Настройка окружения
Создайте файл `.env` в корневой папке проекта и добавьте туда ваш токен:

```bash
# Пример содержимого .env
BOT_TOKEN=ваш_токен_здесь
```

### 3. Запуск
Выполните команду для сборки и запуска бота в фоновом режиме:

```bash
docker-compose up -d --build
```

### 4. Управление
*   **Просмотр логов:** `docker-compose logs -f`
*   **Остановка бота:** `docker-compose down`

## 📖 Инструкция по использованию

После запуска бота в Telegram используйте кнопки меню:

1.  **🗑 Очистить файлы** — Обязательно нажимайте перед загрузкой новой порции данных, чтобы старые отчеты не смешивались с новыми.
2.  **📁 Загрузка** — Отправьте боту один или несколько `.json` файлов.
3.  **📊 Провести вычисления** — Бот проверит наличие файлов, запросит подтверждение очистки (если нужно) и пришлет Excel-таблицу.

## 🛠 Техническая информация

*   **Язык:** Python 3.11
*   **Библиотеки:** `aiogram` (бот), `pandas` & `openpyxl` (Excel), `docker` (развертывание).
*   **Данные:** Файлы сохраняются в директорию `./data` (подключена как Docker Volume).
*   **Форматирование:** Таблицы автоматически масштабируются для удобного чтения с телефона.

---

## 📂 Структура проекта

*   `bot.py` — Логика взаимодействия с пользователем и FSM.
*   `parser.py` — Извлечение данных из JSON.
*   `exporter.py` — Генерация и стилизация Excel-файлов.
*   `data/` — Локальное хранилище временных файлов (игнорируется Git).
