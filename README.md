# Crypto Parser Telegram Bot\n\nTelegram-бот для обработки `.json` файлов с данными (парсинга) и выгрузки итоговых вычислений в формате `.xlsx` (Excel).\n\n## Инструкция по запуску через Docker Compose\n\nИспользование Docker Compose — это самый быстрый и удобный способ развернуть бота.\n\n### Предварительные требования\n\n1. Установленный [Docker](https://docs.docker.com/engine/install/).\n2. Установленный [Docker Compose](https://docs.docker.com/compose/install/).\n3. Токен API вашего Telegram-бота (его можно получить у [@BotFather](https://t.me/BotFather)).\n\n### Пошаговый запуск\n\n1. **Создайте файл конфигурации среды:**\n   В корне проекта (где находится файл `docker-compose.yml`) создайте файл с названием `.env`.\n\n2. **Добавьте токен бота в файл `.env`:**\n   Откройте `.env` любым текстовым редактором и добавьте свой токен в следующем формате:\n   ```env\n   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ\n   ```\n\n3. **Запустите контейнер:**\n   Откройте терминал в папке проекта и выполните команду для старта:\n   ```bash\n   docker-compose up -d --build\n   ```\n   - Флаг `-d` укажет Docker запустить контейнер в фоновом режиме.\n   - Флаг `--build` заставит Docker пересобрать образ (полезно при первом запуске или после изменения кода).\n\n4. **Проверьте логи (опционально):**\n   Чтобы убедиться, что бот успешно запустился и нет никаких ошибок, проверьте системные логи:\n   ```bash\n   docker-compose logs -f\n   ```\n\n### Остановка бота\n\nДля остановки контейнера и работы бота выполните эту команду в терминале (в корне проекта):\n```bash\ndocker-compose down\n```\n\n### Особенности работы с данными (Volumes)\nВ `docker-compose.yml` настроен том (volume) `./data:/app/data`. \nЭто значит, что все отправляемые боту файлы формата `.json` фактически сохраняются в папку `data` прямо в директории вашего проекта на компьютере или сервере (хост-машине). При перезапусках или обновлениях контейнера ваши загруженные для вычислений файлы никуда не пропадут. Отправить команду на очистку этих файлов можно прямо из меню бота в Telegram.
